# Style failure modes — transitions, remakes, wrap-ups (2026-07)

Source: pancake-review annotations on `fde-is-consulting` (2026-07). Canonical rules now live in [STYLE.md](../STYLE.md) §2–3 and the editor checklist; the editor prompt in `scripts/article_pipeline.py` mirrors them. This note is the regression list.

| Failure | Annotation signal | Fix |
|---|---|---|
| Bland / throat-clearing lead-in | "Bland. Just say that more and more it's an AI agent." | Delete scaffolding; open with the concrete claim. |
| Interstitial transition | "I hate these interstitial transitions… Prefer 'We saw this at Airtable.'" | Cut "in retrospect, a case study…"; start at the example. |
| Announcer lead-in | "Again I hate these lead in sentences." | Cut "There's a sharper version of that mistake…"; start the claim. |
| Remake / overexplain | "Cut. We remake this point like 7 times…" | Keep the first landing; delete punchier restatements. |
| Weak generic framing | "The layer up here is wrong… Harness is core, prompts/tools is FDE." | Prefer the direct ownership claim over metaphor scaffolding. |
| Relitigating conclusion | "From this point down… wrap this puppy up." | Replace restated Lego/architect paragraphs with a short wrap + one check. |

Editor pass: treat each row as a **blocking** Voice/Structure issue when the draft exhibits it.
