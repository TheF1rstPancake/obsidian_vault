# Guide: The solution design template

This guide has two parts. The paid page is a complete worked example for a fictitious support-triage problem. The blank template sits alongside it as a separate page you can copy into your own doc.

For SEs, SCs, and anyone who needs to turn discovery into a clear recommendation.

## What's inside

- **Worked example:** customer problem first, then solution-agnostic requirements, then the recommendation
- **Blank template:** a copyable version of the same structure
- **Practical follow-through:** responsibilities, timing, and open questions

> [!tip]
> Need the empty version first? Use the [blank solution design template](/guide-solution-design-template-blank/).

> [!note]
> The worked example is for paid subscribers. The blank template is public.
